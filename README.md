# 表格转交扩展

这是一个 Chrome/Edge Manifest V3 扩展：在 Google Sheets 的内部右键菜单中加入“转交表格”，并通过独立控制台显示流程进度和日志。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开“开发者模式”，选择“加载已解压的扩展程序”，选中本目录。
3. 点击浏览器右上角的“表格转交”扩展图标，就会打开独立的自动化控制台，在其中填写目标表格网址和分表名称。
4. 在 A 表左侧选择整行，先按 `Ctrl+C`，再右键选择“转交表格”。程序会自动只提取源表 B 到 BL 列，并从目标表 C 列开始写入到 BM 列。

## 当前边界

程序使用 Sheets API 的 `RAW` 写入，效果等同于 Google Sheets 的 `Ctrl+Shift+V`，不会复制格式。源表整行选择后只保留 B:BL，目标表从 C:BM 开始写入。

## 可靠性

- **写入前预览**：点击"开始转交"会先弹出选区预览，显示前几列的解析结果和起始列判断（源 B→目标 C 等），可以手动切换"从 A 列 / 从 B 列开始"，确认后才会写入，避免整表错列。
- **顶部插入且防覆盖**：忽略第 1、2 行表头，从第 3 行开始把新数据放在最上方；顶部空位不够时只插入缺少的行，目标表中已有数据和中间空行整体下移，不会被覆盖。
- **断点续传**：数据写入成功后会记录位置和选区内容。如果后续步骤（智能补全、交接报告）失败，再次点击"开始转交"不会重复写入数据，只会补完剩余字段；全部成功后记录自动清除。
- **空行过滤**：源选区中间的全空行不会占用目标表的行位。
- **授权**：网页授权不再每次强制弹出同意页面；token 带过期时间，过期自动刷新并重试一次（HTTP 401），流程中途不再因凭证过期中断。
- **单行容错**：某一行报告调用 LLM 失败时只跳过该行并记入日志，其余行和后续步骤照常完成。
- **日期归档**：交接报告历史能正确识别表格里的日期单元格（包括 Sheets API 返回的序列号格式、日在前的法式写法、中文年月日等），按日期筛选可用；实在无法识别的行归入“（无日期）”分组并排在最后。
- **同一行只留最后一次**：交接报告历史以源表行为准，同一行重复提交时旧记录自动被最新一次覆盖（含存量清洗），不会残留不同版本的数据。
- **地区配置即时生效**：后台与控制台改用内容比对判断配置是否变化（原来只看行数，修改/删除配置永远不生效），空读取不会覆盖现有缓存。
- **匹配策略分离**：地区补全（W/X/Y 下拉）用带排序的模糊匹配兜底，避免尼日尔/尼日利亚这类近似名误配；交接报告的群组链接则只做精确匹配，杜绝拿错群的链接。
- **识别质量小结**：每轮流程结束会在日志里输出量化统计（国家/省/市区命中数、AL 拆解成功数、交接链接各级命中数），未命中处直接给出行号和 LLM 原始值，方便持续核对准确率。
- **分隔符写法等价**：`N'Djili` ≡ `Ndjili` ≡ `N-Djili` 这类撇号/连字符/空格差异按精确等价处理，不引入子串猜测。
- **模型输出更稳**：Gemini/Groq 返回不是合法 JSON 时，自动附加严格格式要求重试一次，减少整行跳过。
- **省名规范化提取**：提示词允许模型把行政名做纯规范化改写（Région des savane → Savanes），不算推断。
- **封闭集地理推断（最后兜底）**：省市全部查找落空时，把该国已配置的省州清单交给模型判断归属；只能从清单中逐字选择并二次复核，绝不写入配置外的值，日志标注“(地理推断)”。
- **城市两轮查找**：先对所有提示词（区/公社/市）做精确匹配，全部失败后才进入模糊匹配，短的区名不会再劫持真正能精确命中的城市；配置行命中后省份以配置为准。
- **群组链接逐级精确回退**：交接报告按 城市→省州→国家 逐级精确匹配群组配置分表，命中低层级后同一行还要通过省、国的核对（同名城市/同名省不会拿错群）；某一级缺失或没命中自动落到上一级（只有国家的地区也能拿到国家级群组），但绝不模糊。
- **不再静默丢行**：交接报告去重以源表行为准，两行同名的人都会保留。
- **贴错表保护**：打开目标表后若找不到指定分表标签，会明确报错停止，不会默默把数据准备到当前分表。
- **日志防注入**：执行日志用安全文本渲染，表格单元格原文中的 HTML 代码不会再被执行。
- **更少权限**：移除了用不到的 `tabs` 权限（`chrome.tabs.create` 不需要它），安装时不再提示"读取您的浏览记录"。
